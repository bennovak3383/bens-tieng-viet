# Ben's Tiếng Việt

A Vietnamese speaking app (Southern / Saigon accent): picture flashcards, question-and-answer drills, graded-reader stories, tones, and a teacher page.

The whole app is one file, `index.html`, plus the audio bundles in `audio/`. There is no build step. Progress saves in each person's own browser.

Hosted free on Cloudflare Pages, which redeploys every time this repo changes.
